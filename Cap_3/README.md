# Capítulo 3 — Soluciones

| Ejercicio | Fichero | Contenido |
|---|---|---|
| 3.1 | `Circunferencia.java` | Lectura de teclado, `Math.PI`, formato con `printf` |
| 3.2 | `ClasificacionNumero.java` | `if` / `else if` / `else` |
| 3.3 | `TablaMultiplicar.java` | Bucle `for` |
| 3.4 | `NumeroCifras.java` | Bucle `do-while`, aritmética entera |
| 3.5 | `DiasDelMes.java` | `switch` con sintaxis moderna (flechas) |
| 3.6 | `MaximoArray.java` | Array, recorrido con índice |
| 3.7 | `InversionArray.java` | Array, inversión in situ, método auxiliar |
| 3.8 | `MatrizIdentidad.java` | Matriz bidimensional |
| 3.9 | `EstadisticasBasicas.java` | Array de `double`, media/máximo/mínimo |
| 3.10 | `ClasificadorDiaSemana.java` | `enum DiaSemana` + `switch` sobre enum |
| 3.11 | `RecorridoEstaciones.java` | `enum Estacion`, `values()`, `ordinal()` |
| 3.12 | `AcumulacionSinArray.java` | Acumuladores sin array, valor centinela |
| 3.13 | `PuntuacionesUmbral.java` | Array, producto condicional, contador con umbral externo |

Cada ejercicio es un fichero independiente y ejecutable por separado (`javac NombreFichero.java && java NombreClase`). Los ejercicios 3.10 y 3.11 incluyen el `enum` correspondiente como clase de nivel superior no pública en el mismo fichero que la clase con `main`.
